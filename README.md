Weather Data Analysis

Overview

This project focuses on collecting and analyzing historical weather data from four cities: Astana, Milan, Paris and London.

The main goal is to compare their weather conditions and identify differences in temperature, precipitation, wind speed and seasonal patterns using Python.

Cities

* Astana, Kazakhstan
* Milan, Italy
* Paris, France
* London, United Kingdom

Data

The project will use historical daily weather data for the period 2021–2025.

The main variables include:

* Average temperature
* Maximum and minimum temperature
* Precipitation
* Wind speed
* Relative humidity

Analysis

The project will cover:

* Data collection and cleaning
* Exploratory data analysis
* Temperature and precipitation comparisons
* Monthly and seasonal trends
* Descriptive statistics
* Correlation analysis
* Data visualization

Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
